# Bloodborne Windows Launcher

register: product

## Purpose and users
This is a Chinese desktop launcher for an existing Windows Bloodborne port. Its user wants to start the installed game from Windows or Steam, choose output resolution and temporal reconstruction, and understand the actual requested scene resolution before launch. It must preserve the existing game path, save data, controller choices, preferences, and independently edited renderer settings.

## Confirmed direction
The user selected a clear, restrained desktop utility with light visual polish. Efficiency and legibility take priority over Bloodborne-themed decoration. The critical workflow is resolution, algorithm, mode, then launch. DLSS modes must be selectable beside the algorithm, not hidden under advanced controls while an unrelated disabled FSR preset is displayed.

## Principles
Show controls only when relevant. Distinguish requested settings from runtime measurements. Preserve each algorithm's saved options when switching. Keep custom DLSS DLL selection available. Use Chinese labels, keyboard focus, readable high-DPI text and a resizable window. Avoid nested navigation, ornamental cards and dramatic game artwork. Settings changes apply at the next launch; starting also saves.

## Scene
A Chinese player is configuring the game on a large Windows monitor in a normally lit room, comparing technical options before switching into fullscreen play. A quiet light surface with dark text keeps these short comparisons readable.
